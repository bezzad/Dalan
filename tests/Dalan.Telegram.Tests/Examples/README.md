Saved answers of the Telegram adapter, in the shape of Telegram Bot API 10.4 (2026-11-09).
Each test starts on an empty database, so the first bot, user and message all have id 1.
The date is the fixed clock of the tests (2026-11-16 12:00 UTC) in Unix seconds.
A file id is random, so a test puts "ID" in its place before it compares (`sentPhoto.json`, `userVoice.json`).
